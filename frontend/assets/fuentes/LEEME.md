# Fuentes para dibujar imágenes

Las usa `src/app/[idioma]/opengraph-image.tsx` (la imagen para compartir): el dibujo de imágenes de Next no puede usar
las fuentes de la web, necesita los archivos. Son las mismas familias que la web (`next/font/google`).

| Archivo | Familia | Origen |
|---|---|---|
| `Newsreader-Light.ttf` | Newsreader 300 | Google Fonts (fonts.gstatic.com, v26), descargada el 2026-11-27 |
| `Newsreader-LightItalic.ttf` | Newsreader 300 cursiva | ídem |
| `DMMono-Medium.ttf` | DM Mono 500 | Google Fonts (v16) |
| `HankenGrotesk-Regular.ttf` | Hanken Grotesk 400 | Google Fonts (v12) |

acompañar los archivos con ella.
