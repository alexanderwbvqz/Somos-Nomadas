# Somos Nómadas

Comunidad abierta que conecta emprendedores con talento complementario para fundar empresas.

```
frontend/   Next.js (la web). Ver frontend/README si lo hay y sus comandos: pnpm install, pnpm dev, pnpm test
backend/    Python (la API). Aún sin código: se está definiendo
contrato/   Cómo se conectan las piezas y la descripción de la API
```

Cada carpeta se instala y se prueba por separado. El frontend nunca habla con la base de datos: solo con la API del backend.
